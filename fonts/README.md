Source fonts for the profile cards, from github.com/google/fonts (SIL Open Font License 1.1):

- `Geist[wght].ttf`, `GeistMono[wght].ttf`: © The Geist Project Authors, see `OFL-Geist.txt`
- `Caveat[wght].ttf`: © The Caveat Project Authors, see `OFL-Caveat.txt`

`scripts/render_cards.py` instances these at fixed weights and subsets each card's glyphs into embedded WOFF.
